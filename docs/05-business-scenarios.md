# 业务场景清单与验收口径（P1）

## 1. 调研方式

- 对人事、风控、财务、招采 4 个部门开展需求访谈
- 收集高频问题与现有查询方式
- 根据数据可得性、使用频次、链路复杂度确定优先级

## 2. 场景清单

| 部门 | 场景 | 示例问题 | 建议策略 | 依赖数据/工具 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| 人事 | 制度问答 | 年假申请条件和流程是什么 | Simple + RAG | 制度文档 | P0 |
| 人事 | 招聘流程咨询 | 社招转正周期多久，需要哪些材料 | DAG + RAG | 流程文档、FAQ | P1 |
| 风控 | 条款审查 | 这份合同有哪些付款风险条款 | DAG + React | 合同文本、风险规则库 | P0 |
| 风控 | 合规检查清单 | 根据合同生成合规检查清单 | DAG + React | 合同文本、清单模板 | P1 |
| 财务 | 报销政策问答 | 差旅报销标准和票据要求是什么 | Simple + RAG | 财务制度、报销规则 | P1 |
| 财务 | 单据校验 | 这张报销单哪些字段不满足政策 | DAG + React | 报销单、政策规则 | P2 |
| 招采 | 合同条款问答 | 某项目合同的服务期限是多少 | Simple + RAG | 合同库 | P1 |
| 招采 | 流程节点指引 | 招采流程走到哪一步，下一步做什么 | DAG + RAG | 流程文档、任务状态 | P2 |

## 3. 优先级原则

- P0：数据可得、使用频次高、链路短，适合第一版验证
- P1：数据可得、需要多步推理或检索，用于能力增强阶段
- P2：依赖系统打通、权限或更多工具，放到后期

## 4. 评测集与指标

- 每个 P0/P1 场景沉淀 15-30 条黄金用例
- 首批覆盖人事制度问答与风控条款审查，合计 30-60 条
- 指标：

| 指标 | 口径 |
| --- | --- |
| 任务成功率 | 判定通过/总用例数，需定义判定标准 |
| 拒答率 | 无依据时正确拒答的比例 |
| 溯源率 | 回答可追溯到文档片段的比例 |
| P95 耗时 | 端到端响应耗时 |
| 单任务成本 | 平均 Token 用量与估算成本 |

## 5. 原型路线

| 顺序 | 原型 | 策略 | 阶段 |
| --- | --- | --- | --- |
| 1 | 人事制度问答 Agent | Simple + DAG + RAG | P2/P3 |
| 2 | 风控条款审查 Agent | DAG + React | P3 |
| 3 | 财务报销咨询 Agent | Simple + RAG | P3 可选 |

## 6. 待确认事项

- 各部门联系人、文档与数据权限
- 评测用的真实业务用例是否允许脱敏使用
- 是否接入飞书作为演示入口
- 最终采用哪些量化指标写进简历，需验收后回填实测值
